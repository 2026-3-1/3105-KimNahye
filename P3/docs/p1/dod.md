# Definition of Done (DoD) — Solving Meal

기능이 "완료"되었다고 간주하기 위한 기준.

---

## 코드

- [ ] 기능 코드가 작성되어 있다
- [ ] 관련 유닛/통합 테스트가 작성되어 있다 (핵심 로직)
- [ ] 모든 테스트가 통과한다 (`npm test`)
- [ ] 린트 오류가 없다 (`npm run lint`)
- [ ] 빌드가 성공한다 (`npm run build`)

## API (백엔드)

- [ ] DTO에 유효성 검증 데코레이터가 적용되어 있다
- [ ] 비정상 요청에 적절한 HTTP 상태 코드를 반환한다
- [ ] Swagger 문서가 최신화되어 있다
- [ ] 인증/인가가 필요한 엔드포인트에 Guard가 적용되어 있다

## 화면 (프론트엔드)

- [ ] 기능이 정상적으로 동작한다 (로그인/비로그인 상태 모두 확인)
- [ ] 역할(STUDENT/TEACHER)별 접근 제어가 적용되어 있다
- [ ] 에러 상태(API 실패, 빈 데이터)를 처리한다

## PR

- [ ] PR 설명에 변경 내용이 명확히 작성되어 있다
- [ ] 관련 이슈가 연결되어 있다 (`Closes #N`)
- [ ] 셀프 코드 리뷰를 완료했다
- [ ] CI가 통과되어 있다

## 배포

- [ ] `main` 브랜치에 병합되어 CD가 실행되었다
- [ ] 운영 환경에서 기능이 정상 동작한다
- [ ] 헬스체크가 정상이다 (`GET /api/v1/health`)
