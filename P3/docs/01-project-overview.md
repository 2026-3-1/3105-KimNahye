# Solving Meal — 프로젝트 개요

## 프로젝트 비전

**Solving Meal**은 자취생과 요리 입문자를 위한 **맞춤형 인터랙티브 요리 교육 커리큘럼** 웹 서비스입니다.

YouTube 오픈 데이터를 활용하여 요리 영상을 코스(강의) 형태로 묶고, 학습자는 카테고리·난이도·필요 도구 등의 조건으로 맞는 커리큘럼을 탐색·수강할 수 있습니다.

---

## 개발 단계별 범위

| 단계 | 주제 | 상태 |
|---|---|---|
| **P1** | 기초 인증 + 코스/영상 CRUD | ✅ 완료 |
| **P2** | 장바구니·결제 흐름·이어보기·리뷰·북마크 | ✅ 완료 |
| **P3** | 운영형/외부연동+관측성 — 결제 모듈(Toss), 구독·알림, 스케쥴러, Webhook, 보안, 모니터링, 성능 최적화 | 🔨 진행 중 |

---

## 핵심 가치

| 가치 | 설명 |
|---|---|
| 🎯 **커리큘럼 중심** | 단순 영상 나열이 아닌 코스 단위 체계적 학습 |
| 🍳 **자취생 맞춤** | 한식·일식·중식·양식·베이킹 등 실생활 요리 카테고리 |
| 🎥 **YouTube 연동** | youtubeVideoId 기반으로 별도 파일 업로드 없이 영상 관리 |
| 👩‍🏫 **교사/학생 역할 분리** | 선생님(TEACHER)이 코스를 생성·관리, 학생(STUDENT)이 수강 |
| 🔔 **알림 연동** | 이메일·디스코드 Webhook으로 수강 완료·신규 강의 알림 |
| 🔒 **운영 보안** | Helmet, Throttler, XSS 방어, SQL 인젝션 차단 |
| 📊 **관측성** | Winston 구조화 로그 + Prometheus 메트릭 + 헬스체크 |

## 대상 사용자

### 학습자 (STUDENT)
- 자취 초보, 혼밥족, 요리 입문 성인
- 특정 도구(에어프라이어, 오븐 등)나 카테고리(한식, 베이킹 등)에 맞는 레시피를 배우고 싶은 사람

### 선생님 (TEACHER)
- 요리 YouTube 채널 운영자 또는 요리 강사
- 자신의 YouTube 영상을 코스로 묶어 커리큘럼화하려는 크리에이터

## 핵심 기능 (P1~P3 누적)

### 학습자 기능

| ID | 기능 | 설명 | 단계 |
|---|---|---|---|
| F1 | 코스 탐색 | 카테고리·난이도·필요 도구·재생 시간으로 필터링 | P1 |
| F2 | 코스 상세 | 영상 목록·총 재생 시간·선생님 정보 확인 | P1 |
| F3 | 수강 신청 | 장바구니 → 결제(0원 포함) 후 수강 등록 | P2 |
| F4 | 내 코스 | 수강 중인 코스 목록 확인 | P1 |
| F5 | 영상 시청 | YouTube 영상 + 이어보기 + 수강 완료 처리 | P2 |
| F6 | 회원 관리 | 회원가입·로그인·프로필 수정 | P1 |
| F7 | 장바구니 | 무료·유료 강의 모두 장바구니 경유 결제 | P2 |
| F8 | 결제 (토스페이먼츠) | 실결제 SDK 연동. 결제·취소·환불 이력 DB 보관 | P3 |
| F9 | 수강 이력 | 영상별 시청 위치·완료 여부 기록, 이어보기 | P2 |
| F10 | 리뷰 작성 | 영상 1개 이상 완료 시 리뷰 작성 가능 | P2 |
| F11 | 영상 북마크 | 특정 재생 위치 북마크 등록·조회·삭제 | P2 |
| F12 | 알림 구독 | 신규 강의·이벤트 이메일·디스코드 알림 구독 | P3 |

### 선생님 기능

| ID | 기능 | 설명 | 단계 |
|---|---|---|---|
| T1 | 코스 생성 | 카테고리·난이도·필요 도구·가격 설정 | P1 |
| T2 | 영상 등록 | YouTube ID와 영상 정보를 코스에 연결 | P1 |
| T3 | 내 코스 관리 | 코스 목록 조회 + **미리보기** + **수정** | P3 |
| T4 | 코스 수정 | 카테고리·난이도·도구·가격 수정 (`PATCH /teacher/:id`) | P3 |

## 비기능 요구사항 (P3 기준)

| 항목 | 요구사항 |
|---|---|
| 인증 | JWT 액세스 토큰(1h) + 리프레시 토큰(7d), RTR 방식 |
| 역할 | STUDENT / TEACHER / ADMIN enum 기반 권한 분리 |
| 입력 검증 | class-validator + ValidationPipe 전역 적용 |
| 보안 | Helmet HTTP 헤더, @nestjs/throttler Rate Limiting, XSS 방어(helmet CSP), SQL 인젝션 방어(TypeORM 파라미터 바인딩) |
| API 문서 | Swagger (`/api/docs`) 자동 생성 |
| 에러 처리 | HttpExceptionFilter + AllExceptionFilter 전역 처리 |
| 로깅 | Winston 구조화 JSON 로그 + winston-daily-rotate-file |
| 모니터링 | @nestjs/terminus 헬스체크 + prom-client Prometheus 메트릭 |
| 알림 | Nodemailer(이메일) + Discord Webhook HTTP POST |
| 스케쥴러 | @nestjs/schedule 크론 기반 배치 |
| 결제 | 토스페이먼츠 SDK 연동. 모든 결제·취소·환불 이력 DB 보관 |
| 성능 | Redis 응답 캐시, DB 인덱스 추가, React.lazy 코드 스플리팅 |
| 반응형 | 모바일 360px ~ 데스크톱 1920px |
| DB | PostgreSQL + TypeORM (UUID PK) |
