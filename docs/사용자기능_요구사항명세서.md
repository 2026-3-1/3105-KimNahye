# 사용자(학습자) 기능 요구사항 명세서

## 1. 문서 개요

| 항목       | 내용                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| 프로젝트명 | 한끼해결(Solving meal) — 자취생/요리 입문자 대상 인터랙티브 요리 교육 커리큘럼 |
| 대상 역할  | STUDENT (일반 학습자)                                                          |
| 문서 범위  | P1(인증·코스 탐색·수강) + P2(장바구니·이어보기·리뷰·북마크) 학습자 기능        |
| 버전       | P2 기준 (실제 구현 반영)                                                       |

---

## 2. 사용자 정의

### 2.1 페르소나

- 자취 초보 / 혼밥족 / 요리 입문 성인
- 특정 도구(에어프라이어, 오븐 등)나 카테고리(한식, 베이킹 등)에 맞는 레시피를 체계적으로 학습하고 싶은 사용자
- 단순 영상 시청이 아닌 **코스(커리큘럼) 단위**의 학습을 원함

### 2.2 권한

- 기본 회원가입 시 `STUDENT` 역할 자동 부여
- 모든 학습 기능은 JWT Access Token 인증 필요 (공개 리뷰 조회 제외)

---

## 3. 기능 요구사항

### F1. 회원 관리

| ID   | 기능             | 상세 요구사항                                                                                                                                                                                 |
| ---- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1-1 | 회원가입         | 이메일·비밀번호·닉네임·역할(STUDENT/TEACHER) 입력 후 가입. 이메일 unique, bcrypt(saltRounds=10) 해싱                                                                                          |
| F1-2 | 로그인           | 이메일·비밀번호 검증 후 Access Token(1h) + Refresh Token(7d) 이중 발급                                                                                                                        |
| F1-3 | 토큰 자동 재발급 | Access Token 만료 시 Axios 인터셉터가 `/auth/refresh`로 자동 재발급(RTR). `/auth/login`, `/auth/register`, `/auth/refresh`는 인터셉터에서 제외하여 로그인 실패 시 에러 메시지가 그대로 유지됨 |
| F1-4 | 로그아웃         | 해당 유저의 모든 Refresh Token 삭제                                                                                                                                                           |
| F1-5 | 내 정보 조회     | `GET /user/me` 로 닉네임·이메일·역할 확인                                                                                                                                                     |
| F1-6 | 내 정보 수정     | `PATCH /user/me` 로 닉네임 등 프로필 수정                                                                                                                                                     |

**입력 검증**

- 이메일: `@IsEmail` (class-validator)
- 비밀번호: 최소 길이 검증
- 닉네임: 1~50자

**예외 처리**

- 이메일 중복: `409 Conflict`
- 비밀번호 불일치: `401 Unauthorized` (페이지 리다이렉트 없이 빨간 에러 메시지 표시)
- 토큰 만료/위조: `401 Unauthorized`

### F2. 코스 탐색

| ID   | 기능           | 상세 요구사항                                                                                 |
| ---- | -------------- | --------------------------------------------------------------------------------------------- |
| F2-1 | 코스 목록 조회 | `GET /courses/list` — 카테고리·난이도·필요 도구·재생 시간 필터, 페이지네이션(`page`, `limit`) |
| F2-2 | 카테고리 필터  | KOREAN/JAPANESE/CHINESE/WESTERN/BAKING/SIDE_DISH/ONE_DISH 단일 선택                           |
| F2-3 | 난이도 필터    | HIGH(상)/MEDIUM(중)/LOW(하) 단일 선택                                                         |
| F2-4 | 필요 도구 필터 | 다중 선택 가능. 코스의 `requiredTools`(JSONB 문자열 배열)와 매칭                              |
| F2-5 | 재생 시간 필터 | 코스 총 재생 시간(초) 기준 필터링                                                             |
| F2-6 | 코스 상세 조회 | `GET /courses/:id` — 강사 정보, 영상 목록, 총 재생 시간, 영상 수, 카테고리/난이도/도구 표시   |
| F2-7 | 홈(메인)       | 추천/최신 코스 노출, 카테고리 카드 진입 가능                                                  |

**비기능 요구**

- 카드 UI는 모바일(360px) ~ 데스크톱(1920px) 반응형
- 코스 카드에 `📹 N강` 뱃지 표시 (`computedVideoCount` getter)

### F3. 수강 신청 / 내 강의

| ID   | 기능         | 상세 요구사항                                                                                       |
| ---- | ------------ | --------------------------------------------------------------------------------------------------- |
| F3-1 | 수강 신청    | 코스 상세에서 `POST /courses/:courseId/enroll`. Enrollment 레코드 생성                              |
| F3-2 | 중복 방지    | 이미 수강 신청된 강좌 → `409 Conflict`                                                              |
| F3-3 | 존재 검증    | 존재하지 않는 코스/유저 → `404 Not Found`                                                           |
| F3-4 | 내 수강 목록 | `GET /courses/my` — 수강 중인 코스 카드 목록. 강의 수가 정확히 표시되도록 `course.videos` 관계 로드 |

> 결제 모듈이 미구현 상태이므로, 코스 상세에서 직접 무료 수강 신청 가능.

### F4. 영상 시청 & 이어보기 (P2)

| ID   | 기능                    | 상세 요구사항                                                                                                                            |
| ---- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| F4-1 | 영상 상세 조회          | `GET /videos/:id` — 수강 여부 확인 후 진입. 미수강 시 `403 Forbidden`                                                                    |
| F4-2 | YouTube 임베드          | YouTube IFrame Player API로 임베드. 자체 영상 호스팅 없음                                                                                |
| F4-3 | 시청 위치 저장          | `PATCH /videos/:id/progress` — 30초 인터벌마다 `player.getCurrentTime()` 결과를 upsert (실제 재생 위치 기준, 카운터 누적 X)              |
| F4-4 | 시청 위치 조회          | `GET /videos/:id/progress` — 페이지 진입 시 마지막 위치 반환                                                                             |
| F4-5 | 이어보기                | `playerVars.start`에 `watchedDuration` 적용해 자동 재생 위치 이동                                                                        |
| F4-6 | 시청 완료 자동 판정     | 영상 90% 이상 시청 시 `isCompleted=true` 자동 전송                                                                                       |
| F4-7 | **영상 수강 완료 버튼** | "✓ 이 영상 수강 완료" 버튼 클릭 시 즉시 `isCompleted=true`로 마킹. 완료 후에는 "✅ 수강 완료됨"으로 비활성화. 페이지 재진입 시 상태 복원 |

**데이터**

- `video_watch_logs` 테이블에 `(user_id, video_id)` UNIQUE 제약으로 1행 유지
- `watchedDuration`(int 초), `isCompleted`(bool), `lastWatchedAt`(timestamptz) 관리

| ID   | 기능              | 상세 요구사항                                 |

- Navbar에 장바구니 링크(STUDENT 전용)

### F6. 리뷰 (P2)

| ID   | 기능               | 상세 요구사항                                                                                   |
| ---- | ------------------ | ----------------------------------------------------------------------------------------------- |
| F6-1 | 코스 리뷰 목록     | `GET /courses/:courseId/reviews` — 비로그인도 열람 가능                                         |
| F6-2 | 리뷰 작성          | `POST /courses/:courseId/reviews` body `{ rating(1~5), content }`                               |
| F6-3 | **작성 조건 검증** | 코스 영상 중 `isCompleted=true`인 영상이 **1개 이상** 있어야 작성 가능. 미달 시 `403 Forbidden` |
| F6-4 | 중복 방지          | 코스당 리뷰 1개. 이미 작성됨 → `409 Conflict`                                                   |
| F6-5 | 본인 리뷰 수정     | `PUT /courses/:courseId/reviews/:reviewId` — 인라인 편집 폼(별점·텍스트). 본인 외 시도 시 `403` |
| F6-6 | 본인 리뷰 삭제     | `DELETE /courses/:courseId/reviews/:reviewId`                                                   |
| F6-7 | 평균 별점 표시     | 코스 상세 히어로 영역에 `⭐ 평균 (N개 리뷰)` 노출                                               |

> 기존 80% 수강 조건은 **영상 1개 이상 수강 완료**로 완화되었음.

## 5. 비기능 요구사항

| 항목          | 요구사항                                                                         |
| ------------- | -------------------------------------------------------------------------------- |
| 인증          | JWT Access(1h) + Refresh(7d) 이중 토큰, RTR(rotate-on-refresh)                   |
| 인터셉터 정책 | `/auth/login`, `/auth/register`, `/auth/refresh`는 401 자동 재발급 대상에서 제외 |
| 입력 검증     | class-validator + 전역 ValidationPipe (whitelist, transform)                     |
| 에러 처리     | HttpExceptionFilter + AllExceptionFilter, 통일된 `ApiResponseDto<T>` 포맷        |
| 반응형        | 360px ~ 1920px                                                                   |
| API Prefix    | `/api/v1`                                                                        |
| API 문서      | Swagger `/api/docs` (persistAuthorization)                                       |
| 상태 관리     | Zustand(인증, persist) + TanStack Query(서버 캐시)                               |

## 6. 예외 시나리오

| 시나리오                                              | 동작                                                                         |
| ----------------------------------------------------- | ---------------------------------------------------------------------------- |
| Access Token 만료 (일반 API)                          | 인터셉터가 `/auth/refresh` 자동 호출 후 원 요청 재시도                       |
| Refresh Token 만료/폐기                               | `localStorage.clear()` + `/login` 리다이렉트                                 |
| 로그인 실패 (401)                                     | 인터셉터가 무시 → 폼에 에러 메시지 그대로 유지                               |
| 미수강 영상 직접 URL 접근                             | 서버가 `403 Forbidden` 반환                                                  |
| 영상 1개도 수강 완료하지 않은 상태에서 리뷰 작성 시도 | `403 Forbidden`, "영상 1개 이상을 수강 완료한 후 리뷰를 작성할 수 있습니다." |
| 이미 장바구니에 있는 코스 재추가                      | `409 Conflict`                                                               |
