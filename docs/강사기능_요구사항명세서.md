# 강사(선생님) 기능 요구사항 명세서

## 1. 문서 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 한끼해결(Solving meal) |
| 대상 역할 | TEACHER (요리 강사 / YouTube 채널 운영자) |
| 문서 범위 | P1 + P2 강사 기능 |
| 버전 | P2 기준 (실제 구현 반영) |

---

## 2. 사용자 정의

### 2.1 페르소나

- 요리 YouTube 채널 운영자, 요리 강사, 푸드 크리에이터
- 기존 YouTube 영상을 **코스(커리큘럼)** 단위로 묶어 학습자에게 제공하고 싶은 사용자
- 영상 파일을 별도 호스팅하지 않고 **YouTube 영상 ID**만으로 콘텐츠 운영

### 2.2 권한

- 회원가입 시 `role = TEACHER` 선택
- TEACHER 전용 API는 `RolesGuard` + `@Roles(UserRole.TEACHER)` 데코레이터로 보호
- TEACHER 전용 페이지는 프론트의 `ProtectedRoute`로 보호 (P2)

---

## 3. 기능 요구사항

### T1. 강사 회원가입/로그인

| ID | 기능 | 상세 요구사항 |
|---|---|---|
| T1-1 | 강사 회원가입 | 회원가입 시 `role: "teacher"` 지정 |
| T1-2 | 강사 로그인 | 학습자와 동일한 `/auth/login`. JWT 토큰의 role claim으로 구분 |
| T1-3 | 권한 검증 | TEACHER 전용 엔드포인트 접근 시 `RolesGuard`가 토큰 role 검사 |

**예외**

- 일반 STUDENT 토큰으로 TEACHER API 호출: `403 Forbidden`

---

### T2. 코스 생성/관리

| ID | 기능 | 상세 요구사항 |
|---|---|---|
| T2-1 | 코스 생성 | `POST /teacher` body `{ category, difficulty, requiredTools[], price? }` |
| T2-2 | 카테고리 선택 | KOREAN/JAPANESE/CHINESE/WESTERN/BAKING/SIDE_DISH/ONE_DISH 중 1개 |
| T2-3 | 난이도 선택 | HIGH/MEDIUM/LOW |
| T2-4 | 필요 도구 입력 | `requiredTools` 문자열 배열 (예: `["오븐", "믹서기"]`) — JSONB 저장 |
| T2-5 | 가격 입력 | `price`(int) — 기본값 0 |
| T2-6 | 내 코스 목록 | `GET /teacher` — 본인이 생성한 코스 목록 |
| T2-7 | 코스 소유권 검증 | 코스의 `teacher.id`가 토큰 유저 ID와 일치해야 영상 등록 가능 |

**자동 계산 필드**

- `computedVideoCount`: 코스에 연결된 영상 수 (DB 컬럼 아님, getter)
- `computedTotalDuration`: 영상 `duration` 합계

---

### T3. 영상 등록

| ID | 기능 | 상세 요구사항 |
|---|---|---|
| T3-1 | 영상 등록 | `POST /videos` (TEACHER 전용) body `{ youtubeVideoId, title, duration, courseId }` |
| T3-2 | YouTube ID 검증 | 비어 있지 않은 문자열 (예: `dQw4w9WgXcQ`) |
| T3-3 | 재생 시간 입력 | `duration` 초 단위 정수 |
| T3-4 | 코스 연결 | `courseId` 기반 ManyToOne 관계로 영상이 코스에 속함 |
| T3-5 | 강사 자동 연결 | `teacher` 필드는 토큰의 유저 ID로 자동 채워짐 |
| T3-6 | 영상 상세 조회 | `GET /videos/:id` — 수강한 사용자만 조회 가능 |

**예외**

- 다른 강사의 코스에 영상 등록 시도: `403 Forbidden`
- 필수 필드 누락: `400 Bad Request` (DTO 검증)

---

### T4. 영상 정렬 & 코스 구성

| ID | 기능 | 상세 요구사항 |
|---|---|---|
| T4-1 | 영상 순서 | `Video` 엔티티의 등록 순서로 정렬 |
| T4-2 | 영상 목록 노출 | `GET /courses/:id` 응답의 `videos` 배열로 학생에게 표시 |

> 영상 순서 변경/재정렬 UI는 미구현. 등록 순서 기준으로 노출.

---

### T5. 강사 대시보드 (TeacherCourse 페이지)

| ID | 기능 | 상세 요구사항 |
|---|---|---|
| T5-1 | 코스 카드 목록 | 본인이 만든 코스를 카드 형태로 노출 |
| T5-2 | 코스 카드 클릭 | 영상 등록 페이지(`/videos/register/:courseId`)로 진입 |
| T5-3 | "코스 만들기" 진입 | `/courses/create` 경로로 코스 생성 폼 진입 |

---

## 4. TEACHER 전용 화면(페이지) 명세

| 라우트 | 페이지 | 인증/역할 | 비고 |
|---|---|---|---|
| `/teacher` | TeacherCourse | ✓ TEACHER | 내 코스 목록 |
| `/courses/create` | CreateCourse | ✓ TEACHER | 코스 생성 폼 |
| `/videos/register/:courseId` | RegisterVideo | ✓ TEACHER | 코스에 영상 추가 |

---

## 5. API 일람 (TEACHER 관점)

| Method | Endpoint | 권한 | 설명 |
|---|---|---|---|
| POST | `/teacher` | TEACHER | 코스 생성 |
| GET | `/teacher` | TEACHER | 내 코스 목록 |
| POST | `/videos` | TEACHER | 영상 등록 |
| GET | `/videos/:id` | 수강 사용자 | 영상 상세 |
| GET | `/courses/:id` | 인증 사용자 | 코스 상세 (자기 코스도 같은 API로 조회) |

> `RolesGuard` + `@Roles(UserRole.TEACHER)` 조합으로 TEACHER 강제 검증.

---

## 6. 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| 권한 분리 | UserRole enum (`STUDENT` / `TEACHER` / `ADMIN`) 기반. ADMIN은 향후 확장 |
| 입력 검증 | DTO + class-validator (`@IsString`, `@IsArray`, `@IsEnum`, `@IsInt`) |
| 영상 호스팅 | 자체 업로드 없음. YouTube 영상 ID 참조만 |
| 데이터 구조 | Course 1:N Video, User(teacher) 1:N Course |
| 보안 | TEACHER 전용 라우트는 백엔드 가드 + 프론트 ProtectedRoute 이중 보호 |

---

## 7. 예외 시나리오

| 시나리오 | 동작 |
|---|---|
| STUDENT 토큰으로 코스 생성 시도 | `403 Forbidden` |
| 다른 강사 소유 코스에 영상 등록 시도 | `403 Forbidden` |
| 존재하지 않는 코스 ID로 영상 등록 | `404 Not Found` |
