# Solving Meal — 프로젝트 개요

## 프로젝트 비전

**Solving Meal**은 자취생과 요리 입문자를 위한 **맞춤형 인터랙티브 요리 교육 커리큘럼** 웹 서비스입니다.

YouTube 오픈 데이터를 활용하여 요리 영상을 코스(강의) 형태로 묶고, 학습자는 카테고리·난이도·필요 도구 등의 조건으로 맞는 커리큘럼을 탐색·수강할 수 있습니다.

---

## 핵심 가치

| 가치 | 설명 |
|---|---|
| 🎯 **커리큘럼 중심** | 단순 영상 나열이 아닌 코스 단위 체계적 학습 |
| 🍳 **자취생 맞춤** | 한식·일식·중식·양식·베이킹 등 실생활 요리 카테고리 |
| 🎥 **YouTube 연동** | youtubeVideoId 기반으로 별도 파일 업로드 없이 영상 관리 |
| 👩‍🏫 **교사/학생 역할 분리** | 선생님(TEACHER)이 코스를 생성·관리, 학생(STUDENT)이 수강 |
| 📱 **반응형 SPA** | Vite + React 기반, 모바일~데스크톱 대응 |

---

## 대상 사용자

### 학습자 (STUDENT)
- 자취 초보, 혼밥족, 요리 입문 성인
- 특정 도구(에어프라이어, 오븐 등)나 카테고리(한식, 베이킹 등)에 맞는 레시피를 배우고 싶은 사람

### 선생님 (TEACHER)
- 요리 YouTube 채널 운영자 또는 요리 강사
- 자신의 YouTube 영상을 코스로 묶어 커리큘럼화하려는 크리에이터

---

## 핵심 기능

### 학습자 기능

| ID | 기능 | 설명 |
|---|---|---|
| F1 | 코스 탐색 | 카테고리·난이도·필요 도구·재생 시간으로 필터링 |
| F2 | 코스 상세 | 영상 목록·총 재생 시간·선생님 정보 확인 |
| F3 | 수강 신청 | 원하는 코스에 수강 등록 |
| F4 | 내 코스 | 수강 중인 코스 목록 확인 |
| F5 | 영상 시청 | YouTube 영상 상세 페이지 (수강 여부 확인 포함) |
| F6 | 회원 관리 | 회원가입·로그인·프로필 수정 |
| F7 | 장바구니 | 수강 전 여러 코스를 담아두고 한 번에 결제. 결제 전까지 장바구니 항목 유지 |
| F8 | 결제 (토스페이먼츠) | 장바구니 일괄 결제. 결제·취소·환불 이력 전체 DB 보관 |
| F9 | 수강 이력 관리 | 어떤 영상을 어디까지 봤는지 DB에 기록, 이어보기 지원 |
| F10 | 리뷰 작성 | 코스 80% 이상 수강 시에만 리뷰 작성 가능 |
| F11 | 영상 북마크 | 특정 영상의 특정 재생 위치에 북마크 등록·조회·삭제 |

### 선생님 기능

| ID | 기능 | 설명 |
|---|---|---|
| T1 | 코스 생성 | 카테고리·난이도·필요 도구를 설정하여 코스 등록 |
| T2 | 영상 등록 | YouTube ID와 영상 정보를 코스에 연결 |
| T3 | 내 코스 관리 | 자신이 만든 코스 목록 조회 |

## 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| 인증 | JWT 액세스 토큰(1h) + 리프레시 토큰(7d) 이중 발급 |
| 역할 | STUDENT / TEACHER / ADMIN enum 기반 권한 분리 |
| 입력 검증 | class-validator + ValidationPipe 전역 적용 |
| API 문서 | Swagger (`/api/docs`) 자동 생성 |
| 에러 처리 | HttpExceptionFilter + AllExceptionFilter 전역 처리 |
| 반응형 | 모바일 360px ~ 데스크톱 1920px |
| DB | PostgreSQL + TypeORM (UUID PK, 자동 synchronize) |
| 결제 | 토스페이먼츠 연동. 모든 결제·취소·환불 이력을 자체 DB에 보관 |
| 수강 이력 | 영상별 시청 위치(초) 및 완료 여부를 실시간으로 기록 |
| 리뷰 제한 | 코스 전체 영상의 80% 이상 시청 완료 시에만 리뷰 작성 허용 |
